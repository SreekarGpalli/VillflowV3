How to use
  1. Add keys under Cloud & keys, set mic under Dictation, then Save.
  2. Click in any text field (e.g. Notepad).
  3. Hold Ctrl+Shift+Z, speak, release — text pastes at the cursor.
  4. Hold Ctrl+Shift+X — Edit selection, or Generate if nothing selected.
  5. Ctrl+Shift+C toggles the Scratchpad.
